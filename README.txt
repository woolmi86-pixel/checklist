주원이의 하루 체크리스트 (설치형 웹앱 / PWA)

[구성] index.html, manifest.webmanifest, sw.js, icons/

[폰에 설치하는 방법]
1) 이 폴더를 웹에 올립니다 (HTTPS 필수).
   - 가장 쉬운 방법: app.netlify.com/drop 에 폴더를 끌어다 놓기 (무료, 가입 필요)
   - 또는 GitHub Pages / Vercel / Cloudflare Pages
2) 폰에서 올라간 주소를 엽니다.
   - 안드로이드(크롬): 메뉴(⋮) > '홈 화면에 추가' 또는 '앱 설치'
   - 아이폰(사파리): 공유 버튼 > '홈 화면에 추가'
3) 홈 화면의 아이콘으로 실행하면 전체 화면 앱처럼 열리고, 인터넷 없이도 동작합니다.

[참고] 체크 기록은 그 폰(브라우저)에만 저장됩니다.
